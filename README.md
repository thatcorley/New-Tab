# Re:OS

A super duper epic custom tab screen.

**Live Demo:** [thatcorley.github.io/New-Tab/](https://thatcorley.github.io/New-Tab/)

## About

A very simple new tab screen that has a click, shortcuts, a notepad and a simple 12 character password generator

## Features

- Animated fog boot screen made by [Vanta.js](https://www.vantajs.com/)
- URL Shortcuts
- Notepad
- Password Generator

## Tech stack

- HTML / CSS / JavaScript
- Hosted on GitHub Pages, deployed via GitHub Actions

## Running locally

Clone the repo and save it locally and open `index.html` with a web server due to some features requiring it.

## Deployment

The site auto-deploys to GitHub Pages via GitHub Actions whenever changes are pushed.
